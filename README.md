# Alzheimer LLM Simulation

Educational tool based on Large Language Models (LLMs) for simulating communication strategies in scenarios related to Alzheimer's disease.

This repository contains the source code, synthetic personas, experimental configuration, and generated logs used in the master's research:

**Sistema Baseado em LLMs para Simulação de Cenários de Alzheimer**

## Overview

The system uses synthetic personas representing different stages of Alzheimer's disease to simulate communication scenarios involving family members.

Three synthetic personas are used:

- João — mild stage
- Maria — moderate stage
- Ana — advanced stage

Each persona is associated with two simulated situations, resulting in six scenarios.

For each scenario, two communication strategies are evaluated:

- Confrontation
- Validation

The same persona and scenario information are maintained between both executions, changing only the communication strategy.

The model generates:

1. A suggested response for the family member.
2. A simulated reaction from the synthetic persona.

The experiment therefore consists of 12 model requests.

## Model and Environment

- Python: 3.8.10
- Operating system: Ubuntu 20.04.6 LTS
- Model: GPT-4.1
- Model ID: `openai/gpt-4.1`
- Platform: OpenRouter
- `openai`: 1.88.0
- `python-dotenv`: 1.0.1
- Temperature: 0.2
- Max tokens: 160

## Repository Files

- `simulacao.py` — main experimental simulation script
- `personas.csv` — synthetic personas and simulated scenarios
- `teste_llm.py` — script used to test communication with the language model
- `logs.txt` — logs generated during the final experimental execution
- `requirements.txt` — Python dependencies and versions
- `.env.example` — example environment configuration without an API key

## Installation

Clone the repository:

```bash
git clone https://github.com/euluizaoln/alzheimer-llm-simulation.git
cd alzheimer-llm-simulation
```

Install the dependencies:

```bash
pip install -r requirements.txt
```

## API Configuration

The system accesses GPT-4.1 through OpenRouter.

Create a `.env` file based on `.env.example`:

```bash
cp .env.example .env
```

Then add your OpenRouter API key:

```text
OPENROUTER_API_KEY=your_openrouter_api_key_here
```

The `.env` file is ignored by Git and must not be committed to the repository.

## Running the Simulation

Run:

```bash
python simulacao.py
```

The generated interactions are recorded in `logs.txt`.

## Experimental Design

Each simulated situation contains information about the persona, age, Alzheimer's disease stage, symptom, scenario, initial statement, and objective context.

The objective context provides facts about the simulated situation without predetermining the response of the family member or the reaction of the persona.

The persona reaction is generated by the language model during the simulation and is not previously classified as positive or negative.

## Research Scope

This system is a research proof of concept and educational simulation tool.

The synthetic personas and generated interactions do not represent real patients and should not be interpreted as clinical recommendations or as substitutes for professional healthcare guidance.
